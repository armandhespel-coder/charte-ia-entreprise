# Charte IA de l'entreprise, en 1 page

Tes salariés utilisent déjà l'IA (dans 2 entreprises sur 3 de 20 salariés et plus, selon la Banque de France en 2026).
Plutôt que d'interdire, pose 5 règles simples. Copie cette page, remplace ce qui est entre [crochets], envoie-la à ton équipe.

---

## 1. Les outils autorisés

- On utilise **[l'outil validé : ex. ChatGPT Team, Claude Team, Copilot]** avec le **compte de l'entreprise**.
- Jamais un compte perso gratuit pour du travail : selon les réglages, les versions grand public peuvent servir à entraîner les modèles. Les offres entreprise, non.

## 2. Ce qu'on ne colle jamais dans une IA

- Les **données personnelles** : clients, salariés, candidats (noms + coordonnées, CV, santé). C'est le RGPD.
- Les **IBAN**, coordonnées bancaires, mots de passe, accès.
- Les **contrats, devis et prix** non publics.
- Tout fichier marqué **confidentiel**.

> Règle simple : si tu ne l'enverrais pas par mail à un inconnu, tu ne le colles pas.

## 3. Ce qu'on peut faire sans demander

- Reformuler un mail, corriger un texte, traduire, trouver des idées, résumer un document public.
- Avant de coller un vrai cas : **anonymiser** (« Dupont SARL » → « Client A », montants arrondis).

## 4. On relit avant d'envoyer

- L'IA se trompe et invente parfois (chiffres, références, articles de loi).
- Tout ce qui part chez un client ou un partenaire est **relu par un humain**.

## 5. On le dit

- Chacun note dans **[le fichier / le canal partagé]** ce qu'il fait avec l'IA : l'outil et la tâche.
- Pas pour punir : pour savoir ce qui mérite d'être automatisé proprement.
- Une question, un doute : **[prénom du référent IA]**.
